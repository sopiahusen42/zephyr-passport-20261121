An uncaptioned open passport spread for the Grand Duchy of Zephyr, a country that isn't there. A standard-library-only Python program copies the rendered entry.png to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
